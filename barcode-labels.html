🏷️ EigenBarcode-Label-Druck

Eigene EAN-13-Codes für selbstgekochtes. Der Bereich 200… ist laut GS1 für Eigenmarken/In-Store reserviert — kollidiert nie mit echten Produkten und wird von der iPhone-Kamera wie ein normaler EAN gelesen.

  1. Label drucken, ausschneiden, auf den Behälter kleben.
  2. Den Artikel in EverShelf einmal mit diesem Code anlegen: Scanner → Barcode-Tab → Code eintippen → „neues Produkt“ → im Produkt-Formular den Barcode eintragen.
  3. Ab dann: Behälter scannen → Artikel kommt aus der lokalen DB → „📥 AGGIUNGI“.
